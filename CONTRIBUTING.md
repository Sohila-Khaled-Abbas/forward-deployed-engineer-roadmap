# Contributing

Keep the roadmap focused on Sohila's transition from data and automation to customer-facing engineering delivery. Propose a change through a small pull request with the affected user outcome and evidence.

- Edit the curriculum in `dist/data/roadmap.json` and run `node scripts/docs.mjs`.
- Preserve existing topic IDs so progress backups continue to work.
- Cite primary documentation for technical recommendations. Do not copy third-party articles or roadmap nodes.
- Keep existing exposure separate from demonstrated mastery and proposed projects separate from completed work.
- Run `npm test` and `npm run check`; check affected browser interactions and layout.
- Do not commit credentials, real customer records, personal progress exports, generated lab datasets, or private notes.

The project intentionally uses static HTML/CSS/JavaScript and no runtime dependencies. Add a dependency only when it solves a demonstrated need.
